# Классификация постов ВК с помощью нейронных сетей

## Описание проекта
Нейронная сеть для классификации текстов постов по трем группам ВКонтакте. Проект включает полный цикл: парсинг данных, предобработку текста, обучение моделей и интерпретацию результатов.

## Основные возможности
- Парсинг данных из VK API
- Предобработка текста (удаление эмодзи, стоп-слов, лемматизация)
- Обучение нескольких архитектур нейронных сетей
- Сравнение с классическими ML моделями
- Интерпретация результатов и интерактивные предсказания
