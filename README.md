# Классификация постов ВК с помощью нейронных сетей

## Описание проекта
Нейронная сеть для классификации текстов постов по трем группам ВКонтакте. Проект включает полный цикл: парсинг данных, предобработку текста, обучение моделей и интерпретацию результатов.

## Основные возможности
- Парсинг данных из VK API
- Предобработка текста (удаление эмодзи, стоп-слов, лемматизация)
- Обучение нескольких архитектур нейронных сетей
- Сравнение с классическими ML моделями
- Интерпретация результатов и интерактивные предсказания


## Описание файлов и их взаимосвязи

### Основные модули

#### `src/data_loader.py`
**Назначение**: Загрузка данных из VK API и управление данными
**Что делает**:
- Парсит посты из указанных групп ВКонтакте через API
- Сохраняет данные в CSV для повторного использования
- Загружает существующие данные из файлов
**Взаимосвязи**: 
- Использует настройки из `config.py` (токены, ID групп)
- Поставляет данные для `preprocessor.py`

#### `src/preprocessor.py`
**Назначение**: Очистка и подготовка текстовых данных
**Что делает**:
- Удаляет эмодзи, стоп-слова, лишние символы
- Приводит текст к нижнему регистру
- Выполняет лемматизацию (при доступности pymorphy2)
- Кодирует метки групп в числовой формат
**Взаимосвязи**:
- Получает сырые данные из `data_loader.py`
- Передает очищенные данные в `trainer.py`

#### `src/trainer.py`
**Назначение**: Обучение и оценка моделей машинного обучения
**Что делает**:
- Обучает классические модели (Random Forest, Gradient Boosting)
- Создает и обучает нейросетевые архитектуры (LSTM, CNN, CNN-LSTM)
- Оценивает модели с помощью метрик accuracy, precision, recall, F1
- Сохраняет обученные модели и компоненты
**Взаимосвязи**:
- Использует обработанные данные из `preprocessor.py`
- Сохраняет модели для `predictor.py`
- Использует настройки из `config.py`

#### `src/predictor.py`
**Назначение**: Предсказание групп для новых текстов
**Что делает**:
- Загружает обученные модели и компоненты
- Предобрабатывает входной текст аналогично обучению
- Выполняет предсказание с вероятностями
- Возвращает понятный результат пользователю
**Взаимосвязи**:
- Использует модели из `trainer.py`
- Может работать независимо после обучения моделей

### Конфигурационные файлы

#### `config.py`
**Назначение**: Централизованное хранение настроек проекта
**Что содержит**:
- Параметры VK API (токен, версия, ID групп)
- Настройки моделей (размер словаря, длина последовательности)
- Гиперпараметры нейросетей (эпохи, размер батча)
**Взаимосвязи**: Используется всеми основными модулями

#### `requirements.txt`
**Назначение**: Список зависимостей проекта
**Что содержит**: Все необходимые Python-библиотеки с версиями

### Исполняемые файлы

#### `main.py`
**Назначение**: Основной скрипт запуска полного пайплайна
**Что делает**:
1. Загружает данные (из API или файла)
2. Обрабатывает текст
3. Обучает все модели
4. Сохраняет результаты
5. Демонстрирует работу на примерах
**Взаимосвязи**: Координирует работу всех модулей

#### `research.ipynb`
**Назначение**: Исследовательский анализ данных и эксперименты
**Что делает**:
- Визуализирует распределение данных
- Анализирует характеристики текстов
- Тестирует гипотезы и подходы

## Полный рабочий процесс

1. **Загрузка данных** → `data_loader.py` получает посты из VK API
2. **Очистка данных** → `preprocessor.py` подготавливает текст
3. **Обучение моделей** → `trainer.py` создает и обучает классификаторы
4. **Сохранение результатов** → Модели сохраняются в папку `models/`
5. **Предсказание** → `predictor.py` классифицирует новые тексты
